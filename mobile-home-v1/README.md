# X-PM.AI 手机端获客首页初版

2026-10-25 · HTML + CSS + 原生 JavaScript，无构建依赖、无后端、无自动扣费服务。

## 运行

安装 Python 3 后，在本目录运行：

```bash
python3 -m http.server 8080 --directory dist --bind 127.0.0.1
```

打开 http://localhost:8080 。也可直接打开 dist/index.html；剪贴板复制在 HTTPS 或 localhost 下更可靠，失败时提供手动复制。停止服务按 Ctrl+C。

目录：
- dist/index.html：页面文案、表单、隐私说明。
- dist/styles.css：响应式样式，700px 以下单列并显示手机底部咨询入口。
- dist/app.js：主题预选、表单校验、摘要生成、复制、清空。
- PROJECT-STATUS.md：核查范围、证据、未确认事项。
- DEPLOY.md：上线与旧代码安全比对。

## 已实现与边界

三个服务方向 → 本地咨询摘要 → 访客自主复制并通过已有渠道发送。无身份信息字段，不写入 localStorage、不发网络请求、不使用追踪工具，隐私理解勾选默认不选中。改变输入会清除旧摘要；错误或复制失败不显示“预约成功”。不提供医疗诊断或收益承诺，不冒充 PM 官方网站。

这不是在线预约后台，也没有真正的大模型调用或数字员工运行服务。品牌中的 AI 指服务方向。本版不把访客资料上传到 AI。

**真实收件方式尚未确认，因此陌生访客的咨询转化尚未闭环。** 当前私有预览适合审阅；正式公域投放前，必须填入用户授权公开的企业微信/微信二维码或业务邮箱，替换“已有联系渠道”的提示。不要从 Git 提交邮箱推断业务收件地址。

如改成在线留资：另行实现服务端校验、限流/防滥用、访问控制、通知、删除机制，并明确接收方、用途、保存期限、处理地域及撤回方式。未经评估不要直接接入第三方表单或收集健康敏感信息。本初版遵循最少处理原则，不构成对任一地区法律合规的认证。

## 验证

```bash
node --check dist/app.js
```

人工验收：服务卡片选择正确主题；未选主题/未勾选理解说明不能生成；生成内容与输入一致；复制失败有手动路径；清空后字段与摘要消失；编辑后旧摘要失效；320/390/430px 手机尺寸无横向滚动；键盘可操作；刷新不恢复输入。复制后设备剪贴板不属于本页清除范围。
